## 1. 基于VMD-SVDD的滚动轴承性能退化评估

| 项目 | 内容 |
|---|---|
| 作者 | 蒋丽英, 刘明昆, 李贺, 郭濠, 张雷鸣 |
| 期刊 | 沈阳航空航天大学学报, 2023, 40(6): 28-34 |
| URL | https://xuebao.sau.edu.cn/CN/10.3969/j.issn.2095-1248.2023.06.005 |

**方法**：VMD信号分解 → 新筛选指标P（包络谱峭度+Wasserstein距离联合筛选）→ 信号重构 → RMS+波形因子+峰峰值 → SVDD退化评估。IMS数据提前60分钟、XJTU数据提前6分钟检测到早期故障。

## 2. 基于PCA多模型融合的滚动轴承性能退化指标构建

| 项目 | 内容 |
|---|---|
| 作者 | 蒋丽英, 郭濠, 李贺, 刘明昆, 张雷鸣 |
| 期刊 | 沈阳航空航天大学学报, 2024, 41(1) |
| URL | https://cjournal.hep.com.cn/2095-1248/CN/10.3969/j.issn.2095-1248.2024.01.007 |

**方法**：时域+频域+时频域+熵共27特征 → MMPE筛选 → 类softmax赋权 → SVDD/AAKR/GMM三模型融合 → PCA取第一主成分 → SAG-HI。包络谱验证早期故障（BPFO 107.9Hz）。用XJTU-SY Bearing1_1验证，相关性0.97。

## 3. 一种改进基尼指数加权的轴承健康指标构建方法

| 项目 | 内容 |
|---|---|

## 共同技术路线

```
原始振动 → 信号分解(VMD/EEMD/EWT) → 故障频带筛选 → 信号重构
    → 时域+频域特征提取 → 特征融合(PCA/RBM/Transformer/注意力)
    → 健康指标HI → 包络谱物理验证 → RUL预测(LSTM/BiLSTM/PF)
```

**我们没有的前置环节**：信号分解 → 故障频带筛选 → 信号重构。这是我们最需要补的。
