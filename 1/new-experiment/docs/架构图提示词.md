## 数据预处理（图左上）

```
原始轴承振动信号 (25600Hz)
  → 逐轴承 Z-score 标准化
  → 滑动窗口 (窗长1024, 50%重叠)
  → 附加归一化时间位置 t ∈ [0,1]
```

## 模型结构（图中部，核心）

**① 编码器 Encoder (1D-CNN, ~120K参数)**
```
输入: 振动窗口 [1, 1024]
  Conv1d(1→16, k=64,s=8) → BN → GELU
  Conv1d(16→32,k=32,s=4) → BN → GELU
  Conv1d(32→64,k=8,s=2)  → BN → GELU
  Conv1d(64→128,k=4,s=1) → BN → GELU
  Flatten → Linear → 输出: z [128]
```

**② 时序平滑模块 TemporalConv1D**
```
z [T, 128] → 2层时间维1D卷积 (k=7, BN+GELU) → z' [T, 128]
(融合前后邻窗信息，消除逐窗独立预测的高频波动)
```

**③ 解码器 Decoder (转置卷积)**
```
z' → ConvTranspose1d 逐层还原 → x̂ [1, 1024] (重构信号)
```

**④ 时间感知投影头 Time-Aware Projector (核心创新模块)**
```
  z' [128] → SignalFC → h_signal [32]
                              ↘
  t_pos    → TimeEmbed → h_time [32] → Gate(可学习门控) → HI [0,1]
                              ↗
  Gate ∈ [0,1]:  Gate→1 依赖时间先验, Gate→0 依赖信号特征
```

## 损失函数（图右侧，简化标注）

- **重构损失**：x̂ 与原始信号的 MSE
- **增强对比损失**：同窗口两视图互为正样本，其余为负
- **分段时序对比损失**：段内邻近窗口互为正样本
- **值感知单调性损失**：HI越高下降惩罚越重（核心创新）
- **锚点+趋势损失**：早期HI→0，末期HI→1，全局正相关

## 关键数据流

```
x [T,1,1024] → Encoder → z [T,128] → TemporalConv1D → z' [T,128]
                                           ├→ Decoder → x̂ → L_recon
                                           └→ Projector(z', t_pos) → HI → L_physics

x 的两次增强视图 → z₁, z₂ → L_contrastive
```
