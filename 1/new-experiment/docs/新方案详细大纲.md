## 整体架构


## 第一步：VMD 自适应分解

### 1.1 输入

每个 CSV 文件的原始振动信号：`x(t), t = 0..32767, fs = 25600 Hz`

### 1.2 VMD 原理

变分模态分解 (Variational Mode Decomposition) 将信号分解为 K 个带限固有模态函数 (IMF/BLIMF)：

```
x(t) = Σ u_k(t),  k = 1..K

每个 u_k(t) 是一个中心频率为 ω_k 的窄带信号
```

### 1.3 参数自适应选择

| 参数 | 含义 | 取值策略 |
|---|---|---|
| K | 分解模态数 | 中心频率观察法：从 K=2 开始递增，当最后两个 IMF 的 ω 差值 < 0.1·fs 时停止 |
| α | 带宽约束 | 2000 (VMD 标准值，适用于轴承振动) |
| τ | 噪声容忍度 | 0 (标准设置) |
| tol | 收敛容差 | 1e-7 |

**K 的自适应确定**（参考钱门贵 2023 的做法）：
```python
def determine_K(signal, fs, max_K=10):
    for K in range(2, max_K+1):
        u, omega, _ = VMD(signal, K=K, alpha=2000, tau=0, tol=1e-7)
        omega = np.sort(omega)  # 中心频率从小到大
        if K >= 3:
            # 检查最后两个 IMF 的中心频率是否过于接近
            df = (omega[-1] - omega[-2]) * fs
            if df < 0.1 * fs:  # 模态混叠风险
                return K - 1
    return max_K
```

### 1.4 输出

每个 CSV 得到 K 个 IMF，每个 IMF 是 32768 点的时域信号。

## 第二步：IMF 筛选 + 故障频带重构

### 2.1 筛选策略：故障相关性三指标

对每个 IMF，计算三个指标：

**指标 1：包络谱峭度 (Envelope Spectrum Kurtosis)**

```
对 IMF 做 Hilbert 包络 → FFT → 包络谱
在 [fault_freq ± 5Hz] 区间内计算包络谱的峭度
ESK 高 → 该 IMF 包含故障冲击信息
```

**指标 2：故障频率能量比 (Fault Characteristic Energy Ratio, FCER)**

```
FCER = Σ(包络谱在 fault_freq 及 2x,3x 谐波处的幅值) / Σ(包络谱所有幅值)
FCER 高 → 该 IMF 能量集中在故障频率
```

参考钱门贵 2023 的做法，但把基尼指数替换为 FCER。

**指标 3：与原始信号的相关系数**

```
r = Pearson(IMF, 原始信号)
r 过低 → 该 IMF 是噪声或伪分量
r 阈值 = 0.3（经验值）
```

### 2.2 综合筛选规则

```python
def select_imfs(imfs, signal, fault_freq, fs):
    selected = []
    weights = []
    for imf in imfs:
        r = pearsonr(imf, signal)
        if r < 0.3:  # 噪声分量，淘汰
            continue
        
        esk = envelope_spectrum_kurtosis(imf, fault_freq, fs)
        fcer = fault_energy_ratio(imf, fault_freq, fs)
        
        # 综合得分（等权，可调）
        score = 0.5 * esk_norm + 0.5 * fcer_norm
        
        if score > threshold:  # threshold = 所有IMF得分的中位数
            selected.append(imf)
            weights.append(score)
    
    return selected, weights
```

### 2.3 信号重构

```python
# 加权重构：得分越高的 IMF 权重越大
weights = np.array(weights) / sum(weights)
reconstructed = np.sum([w * imf for w, imf in zip(weights, selected)], axis=0)
# reconstructed 是 32768 点，称为"故障频带增强信号"
```

### 2.4 故障频率的确定

不同工况下轴承有对应的故障特征频率（见 `data/bearing_parameters.md`）：

| 工况 | fr (Hz) | BPFO (Hz) | BPFI (Hz) |
|---|---|---|---|
| 1 (2100 rpm) | 35.0 | 107.9 | 172.1 |
| 2 (2250 rpm) | 37.5 | 115.6 | 184.4 |
| 3 (2400 rpm) | 40.0 | 123.3 | 196.7 |

对于无故障标签的轴承：优先使用 BPFO 作为默认故障频率（外圈故障最常见），或用包络谱自动检测能量最集中的频带。

## 第三步：特征提取

### 3.1 特征池 A：故障频带增强信号的特征（每 CSV 一个值）

从 VMD 重构信号中提取。以下每个特征是一个长度 = 该轴承 CSV 数的时间序列：

**时域特征（4 个）**：
```
1. RMS_recon       = sqrt(mean(reconstructed²))
2. Kurtosis_recon  = E[(recon-μ)⁴] / σ⁴
3. Peak_recon      = max(|reconstructed|)
4. CrestFactor_recon = Peak_recon / RMS_recon
```

**频域特征（4 个）**：
```
5. FCER_recon      = 故障频带能量 / 总能量（同第二步的 FCER）
6. ESK_recon       = 包络谱峭度
7. Centroid_recon  = Σ(f·P(f)) / ΣP(f)  （故障频带信号的重心频率）
8. SidebandRatio   = BPFI±fr 边频能量 / BPFI 主频能量
                    （仅内圈故障有意义，外圈故障时跳过）
```

**包络能量特征（3 个）**：
```
9.  BPFO_energy    = 包络谱 [BPFO-10, BPFO+10] Hz 能量
10. BPFI_energy    = 包络谱 [BPFI-10, BPFI+10] Hz 能量
11. TotalEnvEnergy = 包络谱 [0, fs/2] 总能量
```

### 3.2 特征池 B：原始信号的全局特征（每 CSV 一个值）

沿用曾笠玲的方法，从原始信号直接提取。每个特征同样是一条时间序列。

**时域（16 个）**：RMS, 峰值, 峭度, 偏度, 波形因子, 峰值因子, 脉冲因子, 裕度因子, 均值, 方差, 标准差, 峰峰值, 方根幅值, 平均幅值, 最大值, 最小值

**频域（13 个）**：重心频率, 均方频率, 均方根频率, 频率方差, 频率标准差, 以及各子频带能量占比（0-1k, 1k-2k, ..., 11k-12.8k Hz 共 12 个子带取部分）

**时频域（4 个）**：小波包分解 2 层 → 4 个频带的能量占比

> 总计约 33 个全局特征。具体哪些从原始信号提取取决于代码实现，参考曾笠玲论文 2.3 节的完整列表。

### 3.3 特征预处理

```python
# 每个特征是一条时间序列 [n_csv]
# 对每个特征独立做 Min-Max 归一化到 [0, 1]
feature_i = (feature_i - min(feature_i)) / (max(feature_i) - min(feature_i))

# 注意：归一化后在 [0,1] 区间，HI 定义也是 [0,1]
# 两者方向可能不一致（有的特征退化时增大，有的减小）
# 统一方向：退化越严重 → 特征值越大
# 如果某特征退化时减小（如某些频带能量比），取 1 - value
```

## 第四步：四维特征筛选

### 4.1 四个筛选维度

对每个候选特征（来自特征池 A + 特征池 B 的全部 ~43 个特征），计算四个指标：

**维度 1：单调性 Mon**
```
Mon = mean(diff(feature) > 0)   （同之前定义）
衡量特征是否单调变化
```

**维度 2：趋势性 Trend**
```
Trend = (1 + Pearson(feature, t)) / 2          （同之前定义）
其中 t = [0, 1/(N-1), 2/(N-1), ..., 1]
衡量特征是否与时间正相关
```

**维度 3：鲁棒性 Rob**
```
Rob = exp(-std(|diff(feature)|) / mean(|diff(feature)|))   （同之前定义）
衡量特征的抗噪声能力
```

**维度 4：物理忠实度 Phys（新增）**

```python
def phys_score(feature, fault_freq, signal, fs):
    """
    feature: 待评估的特征曲线 [n_csv]
    fault_freq: 轴承故障特征频率 (BPFO 或 BPFI)
    signal: 原始信号（所有 CSV 的完整信号列表）
    fs: 采样率
    """
    # 对每个 CSV，计算包络谱中 fault_freq 附近的总能量
    envelope_energies = []
    for csv_idx in range(len(feature)):
        sig = signal[csv_idx]  # [32768]
        env = abs(hilbert(sig))
        env_fft = abs(fft(env - mean(env)))
        freqs = fftfreq(len(env), 1/fs)
        mask = (freqs >= fault_freq-10) & (freqs <= fault_freq+10)
        energy = sum(env_fft[mask])
        envelope_energies.append(energy)
    
    envelope_energies = np.array(envelope_energies)
    envelope_energies = (envelope_energies - min(envelope_energies)) / \
                        (max(envelope_energies) - min(envelope_energies) + 1e-10)
    
    # 特征值与包络能量的 |Pearson 相关| 
    r, _ = pearsonr(feature, envelope_energies)
    return abs(r)
```

**含义**：Phys 衡量特征曲线与包络故障频率能量曲线的相似程度。Phys = 1 表示特征完美跟踪物理故障，Phys ≈ 0 表示特征与物理故障无关。

### 4.2 交集初选

```python
# 对每个维度单独排序，取前 M 名
M = 15  # 可调

top_mon  = set(argsort(Mon_scores)[-M:])
top_trend = set(argsort(Trend_scores)[-M:])
top_rob  = set(argsort(Rob_scores)[-M:])
top_phys = set(argsort(Phys_scores)[-M:])

# 四维交集
selected = top_mon & top_trend & top_rob & top_phys
```

**和曾笠玲的区别**：她只有三维交集 (Mon ∩ Trend ∩ Rob)，我们加了第四维 Phys，保证入选特征在物理上也是诚实的。

### 4.3 聚类复选（可选）

与曾笠玲一致：当交集初选得到的特征仍过多时，启用聚类复选去除冗余。

```python
# 计算特征间的 Pearson 相关矩阵
corr_matrix = np.corrcoef(selected_features)

# 层次聚类
from scipy.cluster.hierarchy import linkage, fcluster
Z = linkage(1 - abs(corr_matrix), method='average')
# 聚类簇数 = min(8, len(selected) // 2)
n_clusters = min(8, len(selected) // 2)
clusters = fcluster(Z, n_clusters, criterion='maxclust')

# 每簇选离簇中心最近的特征（和曾笠玲一致，纯几何标准）
final_features = []
for c in range(1, n_clusters+1):
    cluster_indices = np.where(clusters == c)[0]
    # 计算簇中心
    center = selected_features[cluster_indices].mean(axis=0)
    # 选离中心最近的（在相关空间中，选其他特征都高度相似的那个）
    distances = np.linalg.norm(
        selected_features[cluster_indices] - center, axis=1
    )
    best_idx = cluster_indices[np.argmin(distances)]
    final_features.append(selected[best_idx])
```

聚类复选只解决一个问题：**"这些特征是否高度相似"**。不涉及 Mon/Trend/Rob/Phys 的任何加权。那些质量判断已在交集初选中完成。

## 第五步：Transformer 特征融合 → HI

### 5.1 整体思路

经筛选后得到 8~12 个特征（每个特征是长度 = n_csv 的时间序列）。用 Transformer Encoder 融合多特征，延续曾笠玲路线。

### 5.2 输入结构

```
输入: [n_csv, n_features]  特征矩阵
  n_features = 8~12（筛选后的最终特征数）

每个特征 = Transformer 的一个 token 位置
每个 CSV 时刻 = 一个样本，各 token 的输入值是归一化后的特征值

具体地：
  对于 t ∈ [0, n_csv-1]:
    输入向量 = [feature_1(t), feature_2(t), ..., feature_n(t)]
    → 视为一个长度为 n_features 的"序列"
    → 每个位置是一个标量，通过 embedding 层映射到 d_model 维
```

### 5.3 模型结构

```python
class TransformerHIFusion(nn.Module):
    def __init__(self, n_features, d_model=64, n_heads=4, n_layers=2):
        # 特征嵌入：每个标量特征 → d_model 维向量
        self.feature_embedding = nn.Linear(1, d_model)
        
        # 位置编码（可学习）：区分不同特征类型
        self.pos_embedding = nn.Parameter(torch.randn(1, n_features, d_model))
        
        # Transformer Encoder
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model, nhead=n_heads, 
            dim_feedforward=128, dropout=0.1, 
            activation='gelu', batch_first=True
        )
        self.encoder = nn.TransformerEncoder(encoder_layer, num_layers=n_layers)
        
        # 输出投影
        self.output = nn.Sequential(
            nn.Linear(d_model, 16),
            nn.GELU(),
            nn.Linear(16, 1),
            nn.Sigmoid()
        )
    
    def forward(self, x):
        # x: [B, n_features]  一个 batch 包含多个 CSV 时刻
        x = x.unsqueeze(-1)                              # [B, n_features, 1]
        x = self.feature_embedding(x)                    # [B, n_features, d_model]
        x = x + self.pos_embedding[:, :x.shape[1], :]   # + 位置编码
        
        x = self.encoder(x)                              # [B, n_features, d_model]
        x = x.mean(dim=1)                                # 全局池化 → [B, d_model]
        HI = self.output(x).squeeze(-1)                  # [B]
        return HI
```

### 5.4 训练策略

```
输入：筛选后的特征矩阵 [n_csv, n_features]
损失：
  L = λ₁·L_mono + λ₂·L_trend + λ₃·L_anchor
  （不包含重构损失，因为输入是特征不是信号）

训练方式：逐轴承训练（同之前方案）
  → 每步处理一个轴承的全部 CSV 特征序列

超参数：
  d_model = 64, n_heads = 4, n_layers = 2
  λ₁ = 2.0, λ₂ = 0.3, λ₃ = 0.5
  lr = 1e-3, epochs = 200, optimizer = Adam
```

### 5.5 HI 粒度

```
特征提取粒度：每个 CSV 一个值
     ↓
每个 CSV 输出一个 HI 值
HI = [n_csv]  长度 = 该轴承的 CSV 文件数
```

对于后续使用，CSV 级别的 HI 已足够表征退化趋势。

## 第六步：评估

### 6.1 三个核心指标

沿用领域标准的三个指标（曾笠玲、钱门贵、梁洁琳等一致使用）：

```
Mon (单调性)  = mean(diff(HI) > 0)

Trend (趋势性) = (1 + Pearson(HI, t)) / 2
                 其中 t = [0, 1/(N-1), ..., 1]

Rob (鲁棒性)   = exp(-std(|diff(HI)|) / mean(|diff(HI)|))
```

不计算综合评分（Composite Score），三个指标各自独立报告。物理验证（包络 FPT、Pearson 相关）和基线对比在后续阶段补充。
