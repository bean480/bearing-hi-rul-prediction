# 轴承寿命预测实验方案
## 基于"机理-数据-模型协同驱动"框架

---

## 一、创新性分析

申请书的核心框架是**"机理-数据-模型三层协同驱动"**，在现有文献中有明确的差异化定位：

### 与现有方法的本质区别

| 方法类别 | 代表工作 | 核心局限 | 申请书的改进 |
|---------|---------|---------|------------|
| 纯深度学习 | CNN-LSTM, Transformer | 黑盒、依赖大量全寿命数据 | 引入机理知识降低数据依赖 |
| 物理模型法 | Hertz接触+疲劳模型 | 单一失效形式，通用性差 | 多阶段分段建模 |
| 现有数模联动 | 贝叶斯+LSTM | 未融入故障机理，三者缺乏协同 | 三层显式协同+交互更新 |

### 四个具体创新点

1. **显式建模"磨合自愈"阶段**：现有方法几乎都假设退化单调递增，申请书用线性模型单独建模HI下降段
2. **不确定性量化**：用熵权法融合准度/置信度/置信区间三维指标，基于类比推理量化预测不确定性
3. **ConvLSTM扩充早期HI**：针对早期数据稀缺的专项设计，而非简单数据增强
4. **双向约束器**：解决粒子滤波局部观测导致轨迹漂移的问题

---

## 二、数据集选择

**主数据集：XJTU-SY（西交大）**
- 2种工况，15个轴承全寿命数据
- 退化过程清晰，磨合自愈现象明显，适合验证三阶段建模

**验证数据集：PHM2012（FEMTO-ST）**
- 3种工况，17个轴承全寿命数据
- 用于跨数据集泛化验证

## 三、整体实验流程

```
原始振动信号
    ↓
实验1：健康指标构建（机理-数据联动）
    双谱边频带特征 + 包络平方幅值谱 → 熵权法融合 → 复合HI
    ↓
实验2：退化阶段自动划分（机理驱动）
    滑动窗口斜率分析 → 识别平稳/磨合自愈/加速退化三阶段
    ↓
实验3：ConvLSTM健康指标扩充（数据驱动）
    用历史轴承数据预测目标轴承早期HI（留一法验证）
    ↓
实验4：多段退化模型 + 粒子滤波RUL预测（核心）
    SKF判断阶段 → 切换对应模型 → PF动态更新参数 → 双向约束器
    ↓
实验5：不确定性量化验证
    不同已知数据比例下的不确定性分数变化趋势
    ↓
实验6：跨数据集泛化（XJTU-SY → PHM2012）
```

## 四、详细实验方案

### 实验1：健康指标构建

**目标**：构建能反映三阶段退化的复合HI

**步骤**：
1. 时间窗口：1024点，50%重叠滑动
2. 特征提取：
   - 双谱分析：计算BPFO/BPFI/BSF对应频率的边频带幅值
   - 包络平方幅值谱（ESAS）：Hilbert变换 → 取模 → 平方 → FFT
3. 特征评估：趋势性（Trendability）、单调性（Monotonicity）、鲁棒性（Robustness）
4. 熵权法融合 → 输出复合HI曲线

**验收标准**：Trendability > 0.9，HI曲线可视化能清晰看到三阶段

---

### 实验2：退化阶段自动划分

**目标**：自动识别平稳退化、磨合自愈、加速退化三个阶段

**步骤**：
1. 对HI曲线做滑动窗口（窗口=总长度10%）线性拟合，得到斜率序列
2. 阶段判断规则：
   - `|slope| < ε₁` 且方差小 → 平稳退化
   - `slope < -ε₂` → 磨合自愈
   - `slope > ε₃` 且持续增大 → 加速退化
3. 消融实验：单阶段指数模型 vs 三阶段分段模型，对比最终RUL误差

---

### 实验3：ConvLSTM健康指标扩充

**目标**：解决早期数据稀缺问题

**设置**：留一法，用14个轴承训练，预测第15个

| 输入已知比例 | 预测目标 | 评估指标 |
|------------|---------|---------|
| 前10% HI | 后90% HI | RMSE/MAE |
| 前20% HI | 后80% HI | RMSE/MAE |
| 前30% HI | 后70% HI | RMSE/MAE |

**对比基线**：LSTM、GRU、Transformer

---

### 实验4：核心RUL预测

**退化模型**：
- 平稳/加速阶段：`HI(t) = a·exp(b·t) + ε`，`ε ~ N(0, σ²)`
- 磨合自愈阶段：`HI(t) = c·t + d + ε`

**在线预测流程**：
1. SKF实时判断当前阶段，切换对应状态空间方程
2. 粒子滤波（N=1000）更新参数后验分布
3. 双向约束器：
   - 前向约束：防止预测轨迹偏离历史趋势
   - 后向约束：引导预测终点收敛到失效阈值
4. 输出RUL均值 + 90%置信区间

**评估指标**：

| 指标 | 含义 |
|------|------|
| RMSE | 均方根误差（点估计精度） |
| MAE | 平均绝对误差 |
| PICP | 预测区间覆盖概率 |
| PINAW | 预测区间归一化平均宽度 |

---

### 实验5：不确定性量化验证

**目标**：验证基于类比推理的不确定性量化方法

**步骤**：
1. 对同一轴承，分别用已知10%/20%/.../90%的HI进行预测
2. 计算每次的多维评估指标（准度aei、置信度asti、置信区间widi）
3. 用熵权法融合为单一不确定性分数
4. 验证：不确定性分数随已知数据增多而单调下降

---

### 实验6：跨数据集泛化验证

**目标**：验证方法的泛化能力

**步骤**：
1. 在XJTU-SY上完成训练
2. 直接在PHM2012上测试（零样本迁移）
3. 对比有/无域适应的RMSE差异
