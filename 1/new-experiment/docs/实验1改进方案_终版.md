## 基于分段时序对比学习 + 值感知单调性约束的轴承深度健康指标构建

## 〇、方案演进记录

本方案经过多轮技术讨论，关键修正如下：

| 轮次 | 识别的问题 | 修正 |
|------|-----------|------|
| 1 | 两阶段训练目标冲突 | → 单阶段 warmup 渐进式训练 |
| 2 | 时序对比在随机 batch 中不可行 | → 逐轴承训练，全窗口前向 |
| 3 | 拼接后切分产生跨文件虚假窗口 | → 逐文件独立切分 |
| 4 | 自适应分段有循环依赖 | → 值感知单调性（隐式自适应） |
| 5 | 频域掩码未经验证 | → 移入消融实验 |
| 6 | 全混合留一法无法归因（混了工况+个体因素） | → **同工况留一法**（控制工况变量） |

**最终方案核心**：逐轴承训练 + 增强对比 + 分段时序对比（Wang et al. 改进）+ 值感知单调性（本方案创新）。

## 二、数据预处理

### 2.1 原始数据形态

```
XJTU-SY/
├── Bearing1_1/  (123个CSV, 工况1: 2100rpm, 12kN)
├── Bearing1_2/  ...
└── Bearing3_5/  (50~160个CSV, 工况3: 2400rpm, 10kN)

采样间隔: 约1分钟（文件之间）
```

### 2.2 预处理流水线

```
Step 1: 读取单个CSV
  df = pd.read_csv(csv_path)
  signal = df.iloc[:, 0].values        # 取水平振动, [32768,]

Step 2: 逐轴承 Z-score 标准化（不跨轴承）
  for each bearing:
      all_data = stack(all_csv_signals)  # 拼接仅用于计算 μ, σ
      mean = all_data.mean()
      std  = all_data.std()
      for each csv_signal:
          csv_signal = (csv_signal - mean) / std

Step 3: 逐文件独立切窗（不跨文件拼接）
  for each csv_signal in bearing:
      for start in range(0, 32768 - 1024, 512):
          window = csv_signal[start : start + 1024]
  → 每个CSV产出 (32768 - 1024) // 512 + 1 = 63 个窗口

Step 4: 标注元数据
  每个窗口携带: {
      bearing_id: "Bearing1_1",
      file_index: 0..122,         # 第几个CSV
      window_in_file: 0..62,      # 文件内第几个窗口
      time_position: 0.0..1.0,    # 在轴承全寿命中的归一化位置
  }
```

|------|--------|--------|
| Bearing1_1 | 123 | 7,749 |
| Bearing1_2 | ~110 | ~6,930 |
| ... | | |
| Bearing3_5 | ~50 | ~3,150 |

### 2.4 为什么逐文件切分而非拼接后切分

```
❌ 拼接后切分会在文件边界产生虚假窗口:

文件1尾部 ─┤  ├─ 文件2头部
[...31744..32767][0..1023...]  
       ↑ 虚假窗口跨越60秒无数据间隙

✅ 逐文件切分保证每个窗口完全在一个CSV内部:
文件1: [0..1023], [512..1535], ..., [31744..32767]  ← 63个纯窗口
文件2: [0..1023], [512..1535], ...                  ← 63个纯窗口
       ↑ 没有跨越文件边界的窗口
```

## 三、模型架构

### 3.1 编码器 E_φ

```
输入: x ∈ R^{1×1024}   (单通道振动窗口)
────────────────────────────────────────────
Conv1d(1,  16, k=64, s=8)  → BN → GELU    # → [16, 121]
Conv1d(16, 32, k=32, s=4)  → BN → GELU    # → [32, 23]
Conv1d(32, 64, k=16, s=2)  → BN → GELU    # → [64, 5]
Conv1d(64, 128, k=5, s=1)  → BN → GELU    # → [128, 1]
Flatten → Linear(128, 128) → GELU          # → [128]
────────────────────────────────────────────
输出: z ∈ R^{128}
```

参数量: ~120K

**设计理由**:
- 首层大 kernel (64) + 大步长 (8): 覆盖 64/25600 = 2.5ms，捕获冲击事件
- 逐层压缩: 时间维度 1024 → 121 → 23 → 5 → 1
- GELU 替代 ReLU: 对比学习中对负值梯度更友好
- 4层设计: 比 Wang et al. 的 2层 DNN 深，适配振动信号的层次化时频结构

### 3.2 解码器 D_ψ

```
输入: z ∈ R^{128}
────────────────────────────────────────────
Linear(128, 128) → Reshape(128, 1)
ConvTranspose1d(128, 64, k=5, s=1)  → BN → GELU
ConvTranspose1d(64,  32, k=16, s=2) → BN → GELU
ConvTranspose1d(32,  16, k=32, s=4) → BN → GELU
ConvTranspose1d(16,  1,  k=64, s=8) → Tanh
────────────────────────────────────────────
输出: x̂ ∈ R^{1×1024}
```

### 3.3 HI 投影头 H_ω

```
输入: z ∈ R^{128}
────────────────────────────────────────────
Linear(128, 32) → GELU
Linear(32, 1) → Sigmoid
────────────────────────────────────────────
输出: HI ∈ [0, 1]
```

双层 MLP，Sigmoid 保证 HI 在 [0, 1] 范围内。

```python
def freq_mask_augment(x, fs=25600, num_masks=2):
    """随机衰减部分频带，迫使模型利用多频带信息"""
    X = torch.fft.rfft(x)
    freqs = torch.fft.rfftfreq(len(x), 1/fs)
    
    for _ in range(num_masks):
        center = random.uniform(100, fs/2)
        width = random.uniform(50, 500)
        mask = (freqs.abs() - center).abs() < width
        X[mask] *= random.uniform(0.1, 0.3)
    
    return torch.fft.irfft(X, n=len(x))
```

## 五、损失函数

### 5.1 重构损失

$$L_{recon} = \frac{1}{2T}\sum_{t=1}^{T}\left(\|x_t - \hat{x}_t^1\|_2^2 + \|x_t - \hat{x}_t^2\|_2^2\right)$$

保证编码器保留信号的关键结构，防止表征坍缩。

### 5.2 增强对比损失（SimCLR 标准）

**正样本**: 同一窗口的两个增强视图 (v₁, v₂)
**负样本**: 同一轴承中所有其他窗口的增强视图

$$L_{aug} = -\frac{1}{T}\sum_{t=1}^{T} \log\frac{\exp(\text{sim}(z_t^1, z_t^2)/\tau)}{\sum_{s=1}^{T}\sum_{k\in\{1,2\}}\exp(\text{sim}(z_t^1, z_s^k)/\tau) \cdot \mathbb{I}[(s,k) \neq (t,1)]}$$

其中 sim 为余弦相似度，τ = 0.1。

**学什么**: 表征对噪声和幅值变化的不变性。

### 5.3 分段时序对比损失（Wang et al. 改进）

将同一轴承的全部窗口按时间顺序等距切为 K 段，段内邻近窗口互为正样本。

```python
def segment_temporal_contrast(z, time_positions, K=None, delta=5):
    """
    z: [T, 128] 同一轴承全部窗口的表征
    time_positions: [T] 归一化时间位置
    
    自适应确定段数 K:
      K = max(3, min(10, T // 500))
      例: T=7749 → K=10, 每段约775个窗口
           T=3150 → K=6,  每段约525个窗口
    """
    if K is None:
        K = max(3, min(10, T // 500))
    
    z_norm = F.normalize(z, dim=1)
    
    # 将窗口分配到K个段
    segment_ids = (time_positions * K).long().clamp(0, K-1)
    
    loss = 0
    count = 0
    for seg in range(K):
        seg_indices = (segment_ids == seg).nonzero().squeeze()
        
        # 段内：时间邻近窗口为正样本对
        for i_idx, i in enumerate(seg_indices):
            for j in seg_indices[i_idx+1:]:
                if abs(i - j) <= delta:
                    # 正样本对
                    sim = (z_norm[i] * z_norm[j]).sum() / tau
                    pos_term = sim.exp()
                    
                    # 负样本：同段内不相邻 + 相邻段外的所有窗口
                    neg_sims = 0
                    for k in range(T):
                        if k != i and (abs(i - k) > delta or segment_ids[k] != seg):
                            neg_sims += (z_norm[i] * z_norm[k]).sum().exp() / tau
                    
                    loss += -sim + torch.log(neg_sims + 1e-8)
                    count += 1
    
    return loss / max(count, 1)
```

**与 Wang et al. 的差异**:
- Wang: 固定 K=10 段，所有数据集统一
- 本方案: $K = \max(3, \min(10, T/500))$，自适应轴承的窗口数
- 物理含义：保证每段约 500 个窗口（约 10 分钟的退化过程），段数随轴承寿命长度自适应

### 5.4 值感知单调性损失（本方案核心创新）

**物理直觉**: 轴承越退化，退化越不可逆。HI 值低时（磨合期）可以允许波动，HI 值高时（加速退化期）任何下降都应严惩。

```python
def value_aware_monotonicity_loss(HI, base_penalty=1.0, eps=1e-3):
    """
    HI: [T] 同一轴承的全部HI值
    
    标准铰链损失 * HI权重:
      HI=0.1 时权重≈0.01  → 几乎不惩罚下降
      HI=0.9 时权重≈0.81  → 严格惩罚下降
    """
    diff = HI[1:] - HI[:-1]  # [T-1], 正=上升, 负=下降
    
    # 标准铰链：只惩罚下降
    hinge = F.relu(-diff + eps)  # [T-1], 下降超过eps才惩罚
    
    # 值感知权重：使用后一个窗口的HI值
    # 平方让高低区分更大: HI=0.1→0.01, HI=0.9→0.81
    weights = HI[1:] ** 2  # [T-1]
    
    # 加权铰链损失
    weighted_hinge = weights * hinge  # [T-1]
    
    return base_penalty * weighted_hinge.mean()
```

**数学性质**:

| HI值 | 含义 | 权重 | 对10%下降的惩罚 |
|------|------|------|----------------|
| 0.05 | 健康 | 0.0025 | 0.00025 |
| 0.30 | 磨合末期 | 0.09 | 0.009 |
| 0.60 | 平稳退化 | 0.36 | 0.036 |
| 0.90 | 加速退化 | 0.81 | 0.081 |

同样的下降量，惩罚相差 324 倍。且不存在显式的分段阈值——所有变化都是连续和可微的。

### 5.5 趋势一致性损失

$$L_{trend} = 1 - \rho(HI, \mathbf{t})$$

其中 $\mathbf{t} = [0, \frac{1}{T-1}, ..., 1]$ 为归一化时间轴，$\rho$ 为 Pearson 相关系数。防止 HI 退化到常数。

### 5.6 总损失

$$L_{total} = L_{recon} + \lambda_1 L_{aug} + \lambda_2 L_{seg\_temp} + \lambda_3 L_{value\_mono} + \lambda_4 L_{trend}$$

## 六、训练策略

### 6.1 训练循环

```python
def train(model, train_bearings, epochs=300):
    """
    逐轴承训练: 每步处理一个轴承的全部窗口
    """
    optimizer = Adam(model.parameters())
    
    for epoch in range(epochs):
        # === 动态损失权重（warmup策略）===
        if epoch < 10:
            # warmup: 只开重构+增强对比，先建表征空间
            λ_1, λ_2, λ_3, λ_4 = 0.5, 0.0, 0.0, 0.0
            lr = 1e-4 + (1e-3 - 1e-4) * (epoch / 10)
        elif epoch < 50:
            # 逐步引入分段时序对比
            progress = (epoch - 10) / 40
            λ_1, λ_2, λ_3, λ_4 = 0.5, 0.3 * progress, 0.0, 0.0
            lr = 1e-3
        else:
            # 引入物理约束
            λ_1, λ_2, λ_3, λ_4 = 0.5, 0.5, 1.0, 0.3
            lr = 1e-3 * (1 - (epoch - 50) / 250)  # cosine衰减
        
        set_lr(optimizer, lr)
        shuffle(train_bearings)
        
        epoch_losses = []
        for bearing in train_bearings:
            optimizer.zero_grad()
            
            # bearing.windows: [T, 1, 1024]
            T = len(bearing.windows)
            
            # 数据增强
            v1 = augment_batch(bearing.windows)  # [T, 1, 1024]
            v2 = augment_batch(bearing.windows)  # [T, 1, 1024]
            
            # 编码
            z1 = model.encoder(v1)  # [T, 128]
            z2 = model.encoder(v2)  # [T, 128]
            
            # 解码
            x̂1 = model.decoder(z1)  # [T, 1, 1024]
            x̂2 = model.decoder(z2)
            
            # HI
            HI = model.projector(z1).squeeze()  # [T]
            
            # 损失
            L_recon = ((x̂1 - bearing.windows)**2).mean() + \
                       ((x̂2 - bearing.windows)**2).mean()
            L_recon = L_recon / 2
            
            L_aug = aug_contrastive_loss(z1, z2, tau=0.1)
            
            L_seg_temp = segment_temporal_contrast(
                z1, bearing.time_positions
            ) if λ_2 > 0 else 0
            
            L_value_mono = value_aware_monotonicity_loss(HI) \
                if λ_3 > 0 else 0
            
            L_trend = 1 - pearsonr(HI, bearing.time_positions) \
                if λ_4 > 0 else 0
            
            L_total = L_recon + λ_1*L_aug + λ_2*L_seg_temp + \
                       λ_3*L_value_mono + λ_4*L_trend
            
            L_total.backward()
            optimizer.step()
            
            epoch_losses.append(L_total.item())
    
    return model
```

### 6.2 为什么逐轴承训练是正确的

| 损失 | 计算范围 | 逐轴承训练支持？ |
|------|---------|:---:|
| L_recon | 逐窗口 | ✅ |
| L_aug | 同一窗口的两个视图 | ✅ |
| L_seg_temp | 同一轴承内，段内邻近窗口 | ✅ |
| L_value_mono | 同一轴承全HI序列 | ✅ |
| L_trend | 同一轴承全HI序列 | ✅ |

所有损失需要的配对信息都在单个轴承内部完成。不同轴承之间不需要交互——它们在被视为"不同的退化实验"。

## 七、HI 提取与评估

### 7.1 推理

```python
def extract_HI(model, bearing):
    """对测试轴承提取HI序列"""
    model.eval()
    with torch.no_grad():
        z = model.encoder(bearing.windows)      # [T, 128]
        HI = model.projector(z).squeeze().cpu()  # [T]
    return HI.numpy()
```

与训练的关键区别：**不增强、不采样、不计算对比损失**。

### 7.2 可选的 Savitzky-Golay 平滑

```python
from scipy.signal import savgol_filter
HI_smooth = savgol_filter(HI, window_length=11, polyorder=2)
```

仅用于可视化，不参与训练和评估。

### 7.3 评估指标

| 指标 | 公式 | 含义 | 保留/新增 |
|------|------|------|:---:|
| 单调性 Mon | $\frac{\sum\mathbb{I}(HI_{t+1}>HI_t)}{T-1}$ | 递增比例 | 保留 |
| 趋势性 Trend | $(1+\rho(HI, \mathbf{t}))/2$ | 与线性趋势相关性 | 保留 |
| 鲁棒性 Rob | $\exp(-\sigma(\Delta HI)/\mu(\Delta HI))$ | 抗噪声能力 | 保留 |
| **信噪比 SNR** | $\sigma^2(HI)/\sigma^2(HI_{noise})$ | 趋势清晰度 | **新增** |
| **早期敏感度 ES** | $HI(20\%T) - HI(5\%T)$ | 早期退化响应 | **新增** |
| 综合评分 | 0.5·Mon + 0.3·Trend + 0.1·Rob + 0.1·SNR_norm | — | 调整权重 |

SNR 计算方法：
```python
HI_smooth = savgol_filter(HI, 11, 2)
HI_noise = HI - HI_smooth
SNR = HI_smooth.var() / (HI_noise.var() + 1e-10)
SNR_norm = SNR / (1 + SNR)  # 归一化到[0,1]
```

## 八、实验设计

### 8.1 主实验：同工况留一法交叉验证

#### 为什么不用全混合留一法？

全混合留一法（14轴承训练→1轴承测试）同时混合了三个工况的数据，导致无法归因——性能差异究竟来自"轴承个体差异"还是"工况变化"？同工况留一法控制工况变量，结果可归因。

#### 划分方案

```
XJTU-SY 数据集（15个轴承，3种工况）

┌──────────────────────────────────────────────────────────┐
│ 工况1 (2100rpm, 12kN): 5折留一法                         │
│   Fold 1: 训练=[B1_2, B1_3, B1_4, B1_5],  测试=B1_1     │
│   Fold 2: 训练=[B1_1, B1_3, B1_4, B1_5],  测试=B1_2     │
│   ...                                                    │
│   Fold 5: 训练=[B1_1, B1_2, B1_3, B1_4],  测试=B1_5     │
│   报告: 5折均值 ± 标准差                                  │
├──────────────────────────────────────────────────────────┤
│ 工况2 (2250rpm, 11kN): 5折留一法                         │
│   同上模式                                                │
│   报告: 5折均值 ± 标准差                                  │
├──────────────────────────────────────────────────────────┤
│ 工况3 (2400rpm, 10kN): 5折留一法                         │
│   同上模式                                                │
│   报告: 5折均值 ± 标准差                                  │
├──────────────────────────────────────────────────────────┤
│ 汇总: 15折均值 ± 标准差（作为方法整体性能）               │
└──────────────────────────────────────────────────────────┘
```

**为什么这样划分**：
1. 同工况内训练和测试的信号分布一致（同转速、同负载）→ 可归因
2. 领域标准做法（Jiang et al. 2022, 梁洁琳 2023 等均按同工况划分）
3. 三个工况的结果分开报告 → 可以分析工况复杂性对方法的影响

#### 每折训练数据量

| 工况 | 训练轴承数 | 窗口数（约） | 说明 |
|------|:---:|------|------|
| 工况1 | 4 | ~28,000 | 5个轴承各约7000窗口 |
| 工况2 | 4 | ~20,000 | 退化时长整体比工况1短 |
| 工况3 | 4 | ~15,000 | 退化时长最短 |

4 个轴承 × 几千窗口 对 120K 参数模型完全足够。

### 8.2 消融实验（验证各模块贡献）

**固定测试条件**：工况1，Bearing1_1 为测试轴承（窗口最多、退化最完整、磨合自愈最明显），Bearing1_2~1_5 为训练集。

| 编号 | L_recon | L_aug | L_seg_temp | L_value_mono | L_trend | 验证 |
|:---:|:---:|:---:|:---:|:---:|:---:|------|
| **A** | ✅ | ❌ | ❌ | ❌ | ❌ | 纯 CAE 基线 |
| **B** | ✅ | ✅ | ❌ | ❌ | ❌ | + 增强对比 |
| **C** | ✅ | ✅ | ✅ | ❌ | ❌ | + 分段时序对比 (≈Wang) |
| **D** | ✅ | ✅ | ✅ | ✅ (全局) | ✅ | + 全局单调性 |
| **D'** | ✅ | ✅ | ✅ | ✅ (值感知) | ✅ | **完整方法** |

**核心假设**:
1. B > A: 增强对比的贡献
2. C > B: 分段时序对比的贡献（Wang 的方法在轴承数据上有效）
3. D' > D: **值感知单调性优于全局单调性**（核心创新验证）
4. D' > C: 物理约束的正向贡献

消融实验的关键：D' 是否同时显著优于 D（验证值感知 vs 全局）和 C（验证物理约束 vs 纯对比学习）。

### 8.3 超参数敏感性

固定消融实验设置（工况1, B1_1测试）：

| 参数 | 测试值 | 目的 |
|------|--------|------|
| λ₃ (单调性权重) | [0.5, 1.0, 2.0, 5.0] | 约束强度的影响 |
| δ (段内邻近窗口) | [2, 5, 10, 20] | 时间先验粒度的敏感性 |
| K 固定 vs 自适应 | [固定10, 自适应K] | 自适应分段的效果 |
| 有无频域掩码增强 | [无, 有] | 频域增强贡献验证 |
| 值感知 vs 全局单调性 | 见消融 D' vs D | 核心创新验证 |

### 8.4 对比基线

所有基线方法在相同的数据划分下评估（同工况留一法）。

| 方法 | 来源 | 说明 |
|------|------|------|
| RMS (单特征) | 现有代码 | 最简基线 |
| RMS+BPFO+Envelope + 熵权法 | `hi_fusion.py` | 你现有的手工方法 |
| RMS+BPFO+Envelope + SQP优化 | `optimize_fusion_weights_strict.py` | 最佳手工方法 |
| Wang et al. 方法 (简化迁移) | RESS 2024 | 仅保留子序列级对比+全局单调性 |
| **本方案 (D')** | 提出 | 分段时序对比+值感知单调+趋势约束 |

### 8.5 跨工况泛化（附加实验 → 实验6前置）

```python
# 实验A: 工况1+2 → 工况3
训练: 工况1的5轴承 + 工况2的5轴承 = 10轴承
测试: 工况3的5轴承

# 实验B: 工况1+3 → 工况2
训练: 工况1的5轴承 + 工况3的5轴承

# 实验C: 工况2+3 → 工况1
训练: 工况2的5轴承 + 工况3的5轴承
测试: 工况1的5轴承
```

验证 HI 对未见工况（转速、负载变化）的泛化能力。这是实验6（跨数据集泛化）的前置验证。**不在实验1的主体结果中报告，作为额外亮点。**

### 10.1 指标预期
