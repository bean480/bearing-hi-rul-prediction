**文件**: `experiment/src/models.py`

**改动类型**: 修改方法签名和逻辑


```python

# RNN 输出: rnn_out (Batch, Seq_len, hidden_dim*2), h_n (num_layers*2, Batch, hidden_dim)

    rnn_out, h_n, gates = self.bigru(x_rnn_in, return_gates=True)
```

## 🎯 功能对比

### 修改前

```python
# 使用方式
model = BearingRULModel(...)
output = model(x)  # 只能得到RUL预测值
```

**限制**:
- ❌ 无法访问门控激活值
- ❌ 无法进行可解释性分析
- ❌ 模型是黑盒

### 修改后

```python
# 使用方式1：正常预测（向后兼容）
model = BearingRULModel(...)
output = model(x)  # 仍然只返回RUL预测值

# 使用方式2：提取门控值
output, gates = model(x, return_gates=True)
# gates = {
#     'reset_gate': (batch, seq_len, hidden_dim),
#     'update_gate': (batch, seq_len, hidden_dim),
#     'new_memory': (batch, seq_len, hidden_dim)
# }
```

**优势**:
- ✅ 完全向后兼容
- ✅ 可以提取门控激活值
- ✅ 支持可解释性分析
- ✅ 保持原有功能不变

## ⚠️ 重要提示

### 1. 模型重新训练

**问题**: 自定义GRU的参数结构与标准GRU不同

**影响**: 
- 已训练的模型权重无法直接加载到新模型
- 需要重新训练模型

**解决方案**:

**方案A：重新训练（推荐）**
```bash
# 1. 备份旧模型
mv results/checkpoints/best_model.pth results/checkpoints/best_model_old.pth

# 2. 重新训练
python main.py --mode train

# 3. 运行可视化
python visualize_gates.py
```

**方案B：保留两个版本**
```python
# 在 models.py 中
class BearingRULModel(nn.Module):
    """原始版本，使用标准GRU"""
    def __init__(self, ...):
        self.bigru = nn.GRU(...)  # 标准GRU

class BearingRULModelWithGates(nn.Module):
    """可视化版本，使用自定义GRU"""
    def __init__(self, ...):
        self.bigru = CustomGRU(...)  # 自定义GRU
```

### 2. 性能影响

**计算速度**:
- 标准GRU: 使用cuDNN优化，速度快
- 自定义GRU: 纯Python实现，速度慢2-3倍

**建议**:
- 训练阶段：使用标准GRU（快速迭代）
- 分析阶段：使用自定义GRU（可解释性）

### 3. 内存占用

**门控值大小**:
```
单个样本: (seq_len=30, hidden_dim=64) = 1920个浮点数
100个样本: 约 0.7 MB
1000个样本: 约 7 MB
```

**建议**:
- 分批处理大数据集
- 在`visualize_gates.py`中已限制样本数量
