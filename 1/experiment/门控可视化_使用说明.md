## 📊 可视化功能说明

### 1. 门控激活值热力图

**文件**: `gate_heatmap_*.png`

**内容**:
- 左图：重置门（Reset Gate）激活值
- 右图：更新门（Update Gate）激活值
- 横轴：时间步（0-29）
- 纵轴：隐藏单元（0-63）
- 颜色：激活值（0-1）

**解读**:
- 重置门高激活（红色）：模型正在"遗忘"历史信息
- 更新门高激活（蓝色）：模型正在"保留"历史信息
- 对比健康期、中期、故障期的模式差异

### 2. 门控-RUL演化曲线

**文件**: `gate_evolution.png`

**内容**:
- 左图：重置门平均激活值 vs RUL
- 右图：更新门平均激活值 vs RUL
- 红色/蓝色虚线：二次多项式拟合趋势线

**解读**:
- 观察门控值是否随RUL单调变化
- 检验物理一致性：
  - 更新门应随RUL下降而减小（遗忘健康状态）
  - 重置门应在故障期增强（捕捉新故障模式）

### 3. 健康期vs故障期对比

- 左列：重置门
- 右列：更新门

**解读**:
- 对比两个阶段的门控模式差异
- 识别故障特征对应的门控变化

### 4. 门控统计分布

**文件**: `gate_statistics.png`

## 🔧 代码修改详解

### 修改1：自定义GRU实现

**文件**: `src/custom_gru.py`

**原因**: PyTorch的`nn.GRU`是黑盒，无法访问内部门控值

**解决方案**: 手动实现GRU单元，显式计算门控激活值

**核心代码**:
```python
class CustomGRUCell(nn.Module):
    def forward(self, x, h_prev):
        # 重置门
        r_t = torch.sigmoid(self.W_ir(x) + self.W_hr(h_prev))
        
        # 更新门
        z_t = torch.sigmoid(self.W_iz(x) + self.W_hz(h_prev))
        
        # 新记忆
        n_t = torch.tanh(self.W_in(x) + r_t * self.W_hn(h_prev))
        
        # 新隐藏状态
        h_new = (1 - z_t) * n_t + z_t * h_prev
        
        # 返回门控值
        gates = {
            'reset_gate': r_t,
            'update_gate': z_t
        }
        return h_new, gates
```

### 修改2：模型支持门控提取

**文件**: `src/models.py`

**改动**:
1. 导入自定义GRU: `from .custom_gru import CustomGRU`
2. 替换标准GRU:
   ```python
   # 旧代码
   self.bigru = nn.GRU(...)
   
   # 新代码
   self.bigru = CustomGRU(...)
   ```
3. 修改forward方法，添加`return_gates`参数:
   ```python
   def forward(self, x, return_gates=False):
       if return_gates:
           rnn_out, h_n, gates = self.bigru(x_rnn_in, return_gates=True)
           return rul_pred, gates
       else:
           rnn_out, h_n = self.bigru(x_rnn_in, return_gates=False)
           return rul_pred
   ```

## ⚠️ 注意事项

### 1. 模型兼容性

**重要**: 自定义GRU与标准GRU的参数不兼容！

**影响**:
- 如果你已经训练了模型（使用标准GRU），需要重新训练
- 或者保留两个版本的模型代码

**解决方案**:
```python
# 方案1：重新训练（推荐）
python main.py --mode train

# 方案2：保留旧模型，创建新模型用于可视化
# 在 models.py 中保留 BearingRULModel（旧）
# 创建 BearingRULModelWithGates（新）
```

### 2. 计算开销

自定义GRU比标准GRU慢约**2-3倍**（因为无法使用cuDNN优化）

**建议**:
- 训练时使用标准GRU（快速）
- 可视化时使用自定义GRU（可解释）
- 或者只在最后一个epoch切换到自定义GRU

### 3. 内存占用

提取所有样本的门控值会占用较多内存

**解决方案**:
- 在`visualize_gates.py`中限制样本数量（已实现）
- 或者分批处理

## 🐛 常见问题

### Q1: 运行报错 "ModuleNotFoundError: No module named 'src.custom_gru'"

**原因**: Python找不到模块路径

**解决**:
```bash
# 确保在 experiment/ 目录下运行
cd experiment
python visualize_gates.py
```

### Q2: 可视化图表中文乱码

**原因**: 系统缺少中文字体

**解决**:
```python
# 在 gate_visualizer.py 中修改字体设置
plt.rcParams['font.sans-serif'] = ['Arial']  # 使用英文字体
```

### Q3: 门控值全是0或1

**原因**: 模型未充分训练或梯度消失

**解决**:
- 检查训练损失是否收敛
- 调整学习率或初始化方法
- 增加训练epoch数
