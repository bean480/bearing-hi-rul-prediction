# 实验执行大纲

## 原则

1. 每个实验独立文件夹 `experiments/expN_xxx/`
2. 每个实验只验证一个模块，单独进行
3. 每个实验必须有可视化输出，验证通过后再进入下一步
4. 任何中间结果、图片、数据放在对应实验文件夹内

---

## 实验一：VMD 分解与故障频带重构

**文件夹**：`experiments/exp_vmd_test/`

**目标**：验证 VMD 能正确分解轴承振动信号，筛选出故障相关 IMF，重构出"故障频带增强信号"

**步骤**：
```
1.1 选一个代表轴承的 1~2 个 CSV 文件做 VMD 分解
1.2 观察各 IMF 的时域波形和频谱，确认分解合理
1.3 实现 IMF 筛选（相关系数 + ESK + FCER）
1.4 加权重构信号
1.5 可视化：对比原始信号和重构信号的包络谱
    → 验证重构信号中故障频率是否被增强
```

**参考展示方式**：郑智文论文第三章的 EWD 分解效果图——展示各 IMF 时域/频域、筛选标注、重构前后对比。

**通过标准**：重构信号的包络谱中 BPFO/BPFI 峰值相比原始信号明显增强。

---

## 实验二：特征池提取

**文件夹**：`experiments/exp_feature_pool/`

**目标**：对代表轴承的所有 CSV，提取特征池 A（故障频带特征）和特征池 B（全局特征）

**步骤**：
```
2.1 对每个 CSV：VMD → IMF筛选 → 重构（实验一的流程批量化）
2.2 从重构信号提取特征池 A（10+特征）
2.3 从原始信号提取特征池 B（30+特征）
2.4 可视化：
    → 绘制特征池中每个特征的时间曲线（按时间排列）
    → 观察哪些特征有明显退化趋势
    → 标注哪些特征是"故障频带局部"vs"全局统计"
```

**通过标准**：至少 3~5 个特征（来自 A 和 B 各至少 1 个）呈现清晰的退化趋势。

---

## 实验三：四维特征筛选

**文件夹**：`experiments/exp_feature_screening/`

**目标**：验证四维筛选的效果——能区分"好特征"和"坏特征"

**步骤**：
```
3.1 对每个特征计算 Mon, Trend, Rob（沿用 evaluate.py）
3.2 对每个特征计算 Phys（与包络故障能量的 Pearson 相关）
3.3 交集初选：Mon∩Trend∩Rob∩Phys，M=15
3.4 聚类复选：层次聚类 → 每簇选代表
3.5 可视化：
    → 四维雷达图/柱状图：展示筛选前后特征在各维度上的分布
    → 标注哪些特征被 Phys 维度淘汰（这部分是核心发现）
    → 展示最终入选的 8~12 个特征
```

**通过标准**：Phys 维度至少淘汰掉 2 个"Mon/Trend/Rob 高但物理相关低"的特征，证明 Phys 有独立筛选价值。

---

## 实验四：Transformer 融合构建 HI

**文件夹**：`experiments/exp_transformer_hi/`

**目标**：用筛选后的特征训练 Transformer，输出 HI 曲线

**步骤**：
```
4.1 构建 TransformerHIFusion 模型（按大纲第五章）
4.2 逐轴承训练（Warmup → 引入物理约束）
4.3 提取各轴承的 HI 曲线
4.4 可视化：
    → HI 曲线 + 平滑 HI（选 2~3 个代表轴承）
    → 与筛选前的特征曲线放一起对比
    → 训练损失曲线
4.5 评估：Mon, Trend, Rob 三个指标
```

**通过标准**：选定的代表轴承上，Mon > 0.55, Trend > 0.9, Rob > 0.2。

---

## 实验五：与实验一方法对比

**文件夹**：`experiments/exp_comparison/`

**目标**：在相同轴承上，对比新方案和实验一 Deep HI v2 的表现

**步骤**：
```
5.1 在代表轴承上重新训练 exp1_deep_hi 模型（用相同训练集）
5.2 提取新方案的 HI 和旧方法的 HI
5.3 同一张图上对比两条 HI 曲线
5.4 对比 Mon / Trend / Rob 三个指标
5.5 对比与包络故障频率能量的 Pearson 相关
```

**通过标准**：新方案在 Phys (Pearson 相关) 上显著优于旧方案。

## 执行顺序与依赖

```
实验一 (VMD) ──→ 实验二 (特征池) ──→ 实验三 (筛选) ──→ 实验四 (融合)
                                                              │
                                                              ▼
                                                     实验五 (对比)
```

每个实验通过验证后再进入下一个，不跳跃。
