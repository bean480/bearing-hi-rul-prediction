# 实验原则

## 核心原则

### 1. 严格遵循实验流程
- **一步一步进行**，绝不轻易跳过任何步骤
- **一次只完成最小的改动**
- **每次改动都需要用户确认**
- **改动结果是否通过由用户进行实验验证**，观察实际效果

### 2. 保持批判性精神
- **及时发现可能存在的错误并更改**
- **不确定时立即告知用户可能的风险**，避免对后续实验造成影响
- 不盲目自信，承认不确定性

### 3. 广泛参考文献和实际做法
- **编写代码和设计实验时，优先参考网络文献、论文、开源代码的实际做法**
- **不要轻易自己想象或猜测**，避免出现幻觉
- 例如：数据集格式、API用法、算法实现细节等，都应先查证

## 历史纠错记录

### 错误1：XJTU-SY数据集工况数量
- **错误**：最初认为是2种工况，共10个轴承
- **正确**：3种工况，每种5个轴承，共15个轴承
  - 工况1: 2100rpm, 12kN
  - 工况2: 2250rpm, 11kN  
  - 工况3: 2400rpm, 10kN
- **来源**：https://biaowang.tech/xjtu-sy-bearing-datasets
- **教训**：涉及公开数据集的基本信息，必须先查证官方文档
